# Shopping Discount Calculator – C Programming

## About the Project
This project is a simple shopping discount calculator written in C. It calculates the discount according to the shopping amount and displays the final price.

## Discount Rules

| Shopping Amount | Discount |
|---|---|
| Below 500 TL | 0% |
| 500–999 TL | 10% |
| 1000–1999 TL | 15% |
| 2000 TL and above | 20% |

## Concepts Used
- Variables
- If-else statements
- Conditional logic
- Arithmetic operations
- User input and output

## Example Output
```text
Shopping Amount (TL): 1500
Discount: 225 TL
Final shopping amount: 1275 TL
```

## How to Run
```bash
gcc shopping_discount.c -o shopping_discount
./shopping_discount
```

C
